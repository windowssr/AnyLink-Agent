# 参考资料与证据

核查日期：2026-11-22。接口存在与本产品已集成是不同层级的证据，不能互相替代。

## OpenClaw 官方能力

- [Agent CLI](https://docs.openclaw.ai/cli/agent.md)：描述本地 embedded 路径与常驻 Gateway 的运行所有权，包含 `--local`、`agent exec`、会话、JSON 输出和取消 / 连接丢失语义。
- [自定义 provider](https://docs.openclaw.ai/gateway/config-tools/custom-providers)：支持模型 baseUrl、`openai-completions`、模型清单与代理认证配置。
- [插件工具接口](https://docs.openclaw.ai/plugins/sdk-overview/tools-and-commands.md)：正式工具注册入口，作为云端记忆适配的候选接缝。
- [OpenAI-compatible Agent 入口](https://docs.openclaw.ai/gateway/openai-http-api.md)：是 Gateway 的 Agent 接口，不能据其形状与模型 API 相同就认定它是无 Agent 的模型代理。

这些当前文档不保证全部细节与固定 `2026.11.6` 包相同。安装后用实际包与测试验证配置和扩展点。

## 已核查包元数据

`npm view openclaw@2026.11.6 version dist.tarball engines --json` 返回版本 `2026.11.6`，官方 registry 包地址，以及 Node `>=24.16.0 <25 || >=26.1.0`。这验证包与引擎要求，不验证本机运行成功。

## 本项目证据边界

[V0.1 验收](../implementation/02-validation.md) 证明旧云端聊天与记忆原型可运行，不能证明边缘架构或 Mac harness 已接通。历史研究保留在 [归档资料](../archive/cloud-first-v0.1/20-参考资料与证据.md)。

新架构需要新的本机调用、真实工具与独立停用旧云端 Agent 的验收记录，不能复用旧原型的 9 项模型检查来宣布完成。
