# 身份与设备注册

## 三类身份

主人拥有云端记忆和模型服务；逻辑设备代表 Mac 或 Android；安装绑定代表一次实际 harness 安装。设备名字和客户端传入的 `device_id` 都不能替代认证。

本地 Gateway 管理凭据只用于本机。DeepSeek Key 只保留在服务器。边缘 Agent 只持有访问自己服务器的可撤销设备凭据，权限限于模型代理和授权范围内的记忆。

## 设备接入

主人在可信设置入口生成短期一次性配对凭据；Mac 安装生成本机身份，向云端证明持有配对授权并取得绑定。凭据放系统安全存储，开发阶段若使用文件须 0600 并独立于工具工作区。

接口与密码学方案需在实现中选定并测试，不能把逻辑登记成功当成已完成可信配对。设备重装建立新绑定，不自动继承旧进程的执行权限。

## 云端授权

模型调用按设备鉴权、限额和撤销。记忆来源由绑定确定；同一主人下 device scope 表达适用性，不能据此伪装为多租户隔离。写入仍检查当前 owner、revision 和幂等键。

## 本机授权

本机路径、进程、桌面、麦克风和屏幕权限由本地 harness / 系统控制。服务器模型 API Key 或设备登记不能授予 Mac 操作权限。

## 撤销

撤销设备后拒绝新的模型和记忆调用。已开始的本机动作需由本地取消 / 对账处理；关闭云端凭据不等于已经撤回送入系统的动作。
