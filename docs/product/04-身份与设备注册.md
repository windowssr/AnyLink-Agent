# 身份与设备注册

## 1. 身份层级

| 身份 | 生命周期 | 用途 |
| --- | --- | --- |
| `owner_id` | 主人账号生命周期 | 数据归属、配置、设备与任务授权的根 |
| `assistant_id` | 助理身份生命周期 | 人格、声音、形象和记忆空间 |
| `logical_device_id` | 用户认为是同一台设备的时期 | 设备记忆、目标选择和设备展示 |
| `device_binding_id` | 一次可信安装 / 配对 | 绑定公钥、OpenClaw node 标识、撤销和能力 |
| `connection_id` | 一次网络连接 | 在线传输，不能作为长期设备身份 |
| `conversation_id` / `run_id` | 会话 / 单次运行 | 关联聊天和操作，不能单独作为授权证明 |

逻辑设备与绑定分开：同一台手机重装后可以恢复原来的设备记忆，但新安装必须重新配对，不能自动继承旧公钥和执行权限。

## 2. 注册与配对流程

1. 主人在服务器建立唯一主人身份，初期使用受保护的引导入口完成设置。
2. 客户端本地生成设备密钥，私钥保存在系统安全存储中。
3. 服务器创建短期、单次配对请求；用户在已有可信入口核对设备与能力。
4. 设备模块保存公钥绑定与逻辑设备映射；适配器完成对应 OpenClaw 节点配对。
5. 两侧都完成后才标记执行绑定可用；其中一侧失败，标记 `binding_pending`，不提前授权执行。
6. 注册能力清单和当前能力状态，再开始接收允许的任务。

产品配对与 OpenClaw 配对是两个状态域，需要补偿处理：不得出现产品已撤销、但节点仍被当作可执行目标的状态。

### 日常认证与恢复

V0 使用一次性引导凭据建立主账户；日常通过已配对设备的密钥签名挑战交换短期 access session。挑战绑定服务器 audience、设备绑定、随机 nonce 和有效期，只能消费一次。签名与验证使用成熟库及所选平台支持的算法，不自行实现密码算法。

会话续期绑定设备，refresh 凭据轮换且可撤销。设备被移除时同时失效产品会话、内部绑定和对应节点权限。新设备需要已有可信设备批准，或通过主人保管的恢复入口重新建立信任；不存在“知道逻辑设备 ID 就能登录”的路径。

初始令牌寿命由原型和使用体验确定，保持 access 短期、设备授权可独立撤销。恢复入口与日常设备凭据分开，恢复不会自动恢复被撤销安装的执行权。

## 3. 来源身份的可信传递

直接进入 Gateway 的签名设备连接和经过产品 API 转发的客户端不是同一条链路。产品 API 认证设备后，为内部适配器建立受信请求上下文，包含主人、逻辑设备、绑定、请求、会话和过期时间。

只有内部插件验证过的上下文可以参与作用域选择。客户端提交的 `origin_device_id` 只是待校验声明，服务端必须用认证结果覆盖或拒绝不一致值。

后台任务没有当前说话设备时，保留创建时的 `origin_device_id` 作为来源记录；它不自动携带创建时的执行权限。当前调度需要重新验证任务授权和绑定状态。

## 4. 在线、就绪与能力

设备有 `unpaired`、`binding_pending`、`online`、`offline`、`revoked` 等连接 / 绑定状态。执行就绪单独计算，不能仅由心跳决定。

能力至少分四层：

- 声明支持：设备实现了什么命令。
- 已授予：系统权限和用户设置允许什么。
- 当前可用：前台、解锁、原生 helper 等条件是否满足。
- 本次允许：任务授权和工具策略允许做什么。

调度需要四层同时满足。能力快照带 `capability_revision` 和采集时间；真正执行前设备再次检查，过期快照只用于展示和候选筛选。

## 5. 重连与重装

普通重连只轮换连接 ID，不改变逻辑设备和回执命名空间。重装产生新绑定，默认不允许执行旧绑定下结果未知的步骤。先导入用户确认的记忆归属，再处理旧步骤的对账或明确终止。

对于已撤销绑定发送的迟到回执，实时接口拒绝普通写入；可以保存为隔离的诊断证据，但不能因此恢复执行权。若要纳入任务结果，需要由当前受信流程验证来源和后置条件。

## 6. 设备选择

优先使用用户明确指定的设备；其次是任务规则中固定的目标；再次是该工具唯一符合条件的设备。多台都符合且无法从现有上下文判断时，提出具体选择问题。

默认“当前设备”是交互路由偏好，不是任何任务都可执行的承诺。任务提交后固定目标绑定策略，不能因为另一个设备上线就静默转移。

## 7. 撤销与暂停

用户可以暂停某台设备的新任务，也可以解除绑定。暂停保留记忆和已完成回执；撤销使新步骤无法通过授权检查，并触发连接关闭与未派发工作的暂停。

在途外部动作可能已经发生，撤销不会神奇回滚。云端标记需要对账，客户端应停止接受新步骤并尽力停止可以安全终止的当前动作。

## 8. 验收

覆盖重复配对、同名设备、新安装冒用旧逻辑设备、两端配对状态不一致、绑定撤销与调度同时发生、心跳在线但能力不可用，以及未验签来源不能注入设备记忆上下文。
