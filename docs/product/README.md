# 云端个人助理：产品与系统设计文档集

版本：v0.1。编制日期：2026-11-21。状态：整体设计基线，尚未实施或部署。

## 这个产品是什么

这是一个长期陪伴同一个人的个人助理。它在 Mac 和 Android 上有共同的身份、人格、记忆和任务视图，可以文字聊天、语音交流、呈现虚拟形象、主动联系，并在指定设备上执行操作。

模型调用、长期记忆和任务账本集中在自己的服务器。设备负责呈现和本地执行，可以拥有必要的离线缓存与执行回执，但不会各自形成另一套独立人格和长期记忆。

首选以 OpenClaw 为运行底座。设备记忆、记忆索引和设备任务恢复由自己的扩展实现。本文档中的新接口、字段和状态均为产品设计，不能直接当成 OpenClaw 已提供的 API。

## 已确认的约束

- 首批平台为 Mac 和 Android。
- 优先改造成熟开源项目，先建立可用闭环，再丰富体验。
- 已有 DeepSeek API 服务；密钥在服务器配置，不写入客户端或文档。
- 云端统一记忆，按设备管理局部记忆；统一记忆内包含设备记忆的目录和索引。
- 任务既要保留发起设备，也要明确实际执行设备。
- 要有虚拟形象、主动聊天、语音和电脑 / 手机操作。

## 文档的使用方式

“已确认需求”来自本次讨论；“设计决定”是本方案采用的默认做法；“待验证”表示需要通过原型或真机测试才能承诺。性能数字一律是验收目标或预算，不是实测结果。

同一概念以所属模块为准：记忆以 06 为准，任务状态以 07 为准，实体约束以 14 为准，自有协议以 15 为准。其他文档引用这些约定，不另造一套状态机。

本轮只创建设计文档，没有安装客户端、改变电脑权限、连接服务器、调用付费模型或部署服务。本文档集独立于后续代码仓库；确定技术验证结果后，可以直接迁入项目的 `docs/`。
