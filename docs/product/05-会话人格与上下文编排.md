# 本地会话、人格与上下文

## 会话属于设备 harness

Mac OpenClaw 负责本地 session、模型轮次、工具结果和运行恢复。云端不再维护 `conversation -> cloud Gateway run` 的主交互映射。

共享记忆用于跨设备长期连续性，不能宣称所有原始聊天已经同步。若实现会话导出 / 迁移，应保留设备来源与版本，由目标 harness 显式导入，不并发修改同一活跃运行。

## 上下文由本机组装

本地固定规则与人格版本 → 当前会话历史 → 当前 global 事实 → 来源 / 目标设备目录与相关事实 → 本地工具结果。检索返回事实与 revision，本地按预算选择，云端记忆服务不替 Agent 决定下一步工具。

人格与长期偏好可作为云端版本化记忆读取。一个人格可由多个设备运行实例加载，不要求有一个云端主人格进程。

## 模型请求

本地 harness 发送完整的本次推理输入和工具 schema，经服务器代理调用模型；返回 `tool_calls` 时由本地执行，并由本地提交工具结果。原始输入经过代理不等于已被代理持久保存。

每次运行捕获相关记忆 revision。更正 / 删除后下轮重新读取；正在进行的副作用不悄悄更换所依赖的路径或参数。

## 打断与响应

一个本地运行只有一个响应所有者。取消生成、停止播报和取消本地任务分开处理。文字、音频、字幕和形象使用同一 response ID / generation，迟到流不能恢复旧声音。
