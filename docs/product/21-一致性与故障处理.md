# 一致性与故障处理

## 事实

云端记忆当前 revision 是长期事实权威。设备缓存带版本；更正、删除后下轮读取新版本。索引只能引用当前事实，不能把旧正文恢复为 active。

## 会话

本机 harness 是本机 run / session 权威。UI 断线查原运行和原生历史，不向云端聊天 API 新建替代运行。另一设备不能凭共享 owner 写入同一在途本机 session。

## 模型网络

服务器代理只知道一次推理请求是否被接受 / 流是否完整；不知道整项本机任务是否成功。模型响应丢失不能让代理重启本机任务。代理和 harness 的重试政策必须一起核验。

## 工具

工具可能已经产生副作用但尚未写回结果。恢复先查看本地日志、原生运行和后置条件。读操作重试与写操作重放分开；无法确认时进入待核对。

## 设备与服务恢复

Mac 睡眠 / 重启恢复本机状态，再恢复模型和记忆连接。云端恢复只恢复记忆、配置和访问记录，不派发旧任务。旧的设备绑定不可因恢复过时数据库而自动重新有效。

## 语音与形象

每个本地响应有 generation。取消后丢弃迟到音频和动作，不能由一个新的服务器响应流恢复旧播放。跨设备播放交接未来单独验收。

## 演练

代理断流、记忆 CAS 冲突与删除缓存、UI 断线、本机工具中断、harness 升级、云端备份恢复分别测试。运行结果未知保持可解释状态，不能以再次执行换取表面“恢复成功”。
