# 本地任务与可靠执行

## 调度权威

任务由接收请求的边缘 Agent 建立，由实际执行设备的本地 harness 安排步骤。第一阶段只实现 Mac 本机任务。服务器不规划、认领或派发任务；V0.1 云端待办表不是后续执行队列。

云端可保存用户选择同步的任务结果摘要和设备索引，供其他设备检索。存储副本不能反向指挥执行器，也不能依据模型文字覆盖本机回执。

## 先复用成熟机制

复用 OpenClaw 的 session、运行、工具调用和权限机制。AnyLink 只补本地运行关联、必要的步骤证据与 UI 投影。若原生工具没有可恢复回执，需要补本地接缝并测试，不能因为 harness 成熟就承诺任意操作可靠恢复。

## 状态

本地任务至少区分待处理、等待权限、运行、取消请求、成功、失败、待核对。取消生成不等于取消任务；取消动作不保证撤回已经送入外部应用的操作。

成功须有工具结果与所需后置条件；结果未知保持待核对。不能在进程重启后把运行中任务一律当作未执行。

## 日志与幂等

本地持久记录 task / run / tool call / operation hash / 时间 / 结果与证据。相同输入的传输重试查原运行，不能另开一轮 Agent 自动重做。结果已落盘、展示失败时只恢复展示。

文件写入、外部提交和点击不具备普遍 exactly-once；中断后先检查原运行和真实后置条件。需要重新执行时由明确的新操作表示，不覆盖未知历史。

## 多设备后续

发起设备和目标设备分别持有各自请求与执行记录，以设备间认证协议关联。离线队列由边缘设备持有；服务器只保存共享记忆不能被当作隐式派发服务。Android 暂不施工。
