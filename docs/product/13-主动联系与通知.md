# 设备侧主动联系与通知

## 决策位置

定时提醒、任务完成后的跟进和适度问候由设备 Agent 的本地规则与运行状态触发。需要生成文字时，经服务器模型代理调用模型；服务器不另起一个人格 Agent 主动和用户聊天。

长期目标、时区、免打扰与互动偏好可以放 global 记忆；本地使用当前版本做出展示和发声决定。

## 去重与可解释性

提醒和任务结果使用稳定 interaction ID，本地记录已展示 / 已播放。未来多设备协同需要明确主触达设备与交接协议，不默认所有设备同时问候。

每次主动联系有可查看的原因和关闭入口。用户暂停主动交流后，本地调度立即生效；不得因为云端模型返回了文字就强制播放。

## 不同通知

提醒主人和给他人发送消息是不同动作；外部发送进入本机工具授权与任务证据链。云端记忆服务不承担外发执行。

Android 通知唤起和常驻边界待真机验证；不会把“服务器一直运行”误报为“手机 Agent 一直可执行”。
