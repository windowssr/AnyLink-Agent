# 接口与事件协议

本页区分目标边界，不宣称拟议接口已实现。OpenClaw 本地接口以实际选定版本为准，自有 API 不冒充官方方法。

## 设备本地接口

UI 的会话提交、消息、运行查询、打断、任务详情、取消、工具权限和响应流连接本地 harness / 适配层。事件包含本地 run / response / generation，不能经云端 Agent 二次解释。

语音和形象消费本地响应事件。一次本地消息有稳定请求 ID；连接丢失先查原运行，不重新提交为新任务。

## 云端模型 API

目标接口为 `POST /model/v1/chat/completions` 与 `GET /model/v1/models`；路径在实现时固定。前者接受标准消息、`tools`、`tool_choice`、工具结果与 stream 参数，返回模型原生响应 / SSE。

代理验证设备凭据、允许模型和预算后直接调用 DeepSeek。不使用产品聊天 API，不调用云端 OpenClaw Agent，不执行工具，不写长期会话。

客户端断开应传递取消；上游结果未知时保留明确错误与关联信息，不由代理盲重发。模型厂商是否支持原生请求幂等须核实，不能把自有请求 ID 说成提供商已去重。

## 云端记忆 API

复用当前 memory 查询、创建、修订、删除与设备目录契约，补设备级鉴权。来源设备由认证确定，适用设备是经过校验的数据字段；owner 不接受模型自行指定。

写请求携带稳定幂等键；修订使用 expected_revision，删除使用 If-Match。检索返回当前事实、来源与 revision，不能混入已删旧版。

## 事件和管理

云端可返回 memory revision 变化与服务状态；它们是数据更新，不是本机工具命令。云端管理界面只管理记忆、模型与访问权限，不是对话入口。

## 退出的旧通路

V0.1 的云端 `/v1/conversations/.../messages`、云端 run SSE 和任务待办创建属于历史原型。迁移期间可以只读保留；新 Mac Agent 不再把用户输入提交给它们，也不轮询云端可执行任务。
