# 产品定义与范围

## 目标

一个在 Mac 和 Android 上以本地 Agent 存在的个人助理。用户与设备交互，设备使用自己的系统权限和工具解决问题；人格和长期事实经自己的云端记忆中心保持一致，模型请求经自己的服务器调用提供商。

**交互入口、会话控制、工具循环和执行决定属于设备；长期记忆与模型凭据属于服务器。** 这条边界优先于历史云端方案。

## 第一阶段

先在 Mac 接入成熟 OpenClaw harness，采用独立配置和状态目录。打通本地交互 → 云端模型代理 → 本地工具执行 → 本地展示结果，以及跨新会话的云端记忆读取。Android 后接，不以云端聊天网页替代 Android 本地 Agent。

不自研一套只识别几个固定动作的 Agent 主循环。产品适配代码只负责设备认证、记忆工具、模型网关和本地运行关联等接缝。

## 同一个助理

统一人格和偏好保存在 global 记忆 / 版本化配置中。每个设备有自己的会话、运行状态、权限和执行日志。设备记忆按适用设备过滤，全局目录引用这些事实的当前版本。

## 范围顺序

Mac 成熟 harness 与云端模型 / 记忆接通后，再接本地任务面板、语音、虚拟形象和主动联系。跨设备协作随后单独设计设备间协议，不把服务器重新升级为任务大脑。

## 成功标准

切断旧的云端 Agent 服务后，Mac 仍能完成一次真实工具任务；切换新会话能召回云端 global / Mac 事实；服务器追踪到的是模型和记忆请求，不是下发给 Mac 的逐步命令。
