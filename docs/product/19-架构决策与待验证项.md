# 架构决策与待验证项

修订日期：2026-11-22。历史云端主导 ADR 已归档，以下是当前决策。

## ADR-01：边缘 harness 拥有 Agent 循环

采用。用户交互、上下文、工具循环、任务、系统权限和输出在设备。模型计算在远端不改变 Agent 控制权。Mac 优先成熟 OpenClaw，不重写固定动作调度器。

## ADR-02：云端是记忆与模型服务

采用。服务器保存 global / device 事实和提供商凭据，处理检索、修订、删除与模型转发。必需的身份、审计和配额属于服务基础设施，不扩展为用户任务 Agent。

## ADR-03：共享记忆不等于共享进程

采用。每台设备有本地会话和权限；人格与偏好来自同一版本化 global 数据。跨设备逐字会话迁移、任务协作和播放焦点另行设计，不凭记忆共享假定已同步。

## ADR-04：模型代理不嵌套 Agent

采用。标准模型请求直连 DeepSeek；本地 OpenClaw 不把云端 OpenClaw Agent endpoint 当作 provider。工具调用与结果保持完整协议，由本地 harness 消费。

## ADR-05：执行证据归本机

采用。原生 run / tool call 与实际结果决定本机任务状态。云端摘要只是共享记录，不能驱动重试。未知副作用先对账，不承诺普遍 exactly-once。

## 待验证

固定版 Mac 原生运行与 Node 环境；标准代理对工具流的兼容；memory 插件及来源绑定；本地任务恢复；原生 UI 的产品接入方式。Android 完整本地 harness、语音提供商、形象资产与设备间传输方案后续选择。
