# 语音与低延迟

## 控制与呈现

麦克风、VAD、播放、打断、字幕和响应所有权在当前边缘设备。用户说话进入本地 Agent，而不是由服务器语音 Agent 接管本轮对话。

ASR / TTS / 实时模型可以经服务器统一调用外部服务；这是推理 / 媒体服务调用，不产生另一套工具循环。第一阶段 Mac 文字闭环完成后再接语音。

## 流式链路

设备采音 → 流式识别 → 本地 Agent → 云端模型代理 → 设备流式 TTS / 播放。最终文字、声音和形象共用 response ID 与 generation。旧音频不能在用户打断后恢复。

## 延迟边界

本机先做状态反馈和停止播放，模型推理仍有网络、排队与生成延迟。边缘 Agent 不等于本地模型，也不等于零延迟。分别测端点到首 token、首声及打断时延，不把完整短句耗时当首 token 数据。

## 权限与保留

麦克风权限由系统授予，后台运行遵守实际平台限制。默认不长期保存原始音频；可选择保存转写与必要证据。云端仅提供所选语音 API 的受控转发。
