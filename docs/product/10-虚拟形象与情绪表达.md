# 虚拟形象与情绪表达

形象是设备 UI 的一部分，渲染、拖动、口型、动作和播放都在边缘设备。它订阅本地 Agent 的状态，不直接绕过 Agent 调模型。

V0.5 已加入共享人设、聊天内容的表情动作、受限主动招呼、桌面漫游与中文播报。具体策略与当前限制见[伙伴行为与语音](../implementation/09-companion-behavior-and-voice.md)。

V0.4 Mac 首版使用正常比例的蓝色大肥鱼 Live2D 桌面人物，实现透明浮窗、拖动缩放、举手、竖手指、点头和状态气泡。人物素材只安装在本机，仓库与安装包不分发模型；商业产品使用需确认作者许可。语音与口型仍留到后续阶段，详见[实际施工说明](../implementation/08-desktop-companion.md)。

## 状态

空闲、倾听、思考、执行、说话与等待权限关联同一个本地响应。用户关闭形象只关闭表现层，不自动重启任务或生成另一份回答。

情绪属于表达状态，不能改写事实、权限或任务结果。模型输出的情绪建议由本地表现映射器限制为已支持动作。

## 资产与同步

可复用同一角色资产和版本配置，Mac 与 Android 分别适配渲染。服务器可以把角色偏好作为共享记忆 / 配置保存，但不驱动每帧动画或替设备决定播放时机。

口型按实际音频播放时间轴，字幕与动作关联 response ID / generation。打断清空旧队列，迟到云端数据不能复活旧动作。
