# Mac 本地 Agent

## 运行底座

Mac 原生运行成熟 OpenClaw harness，拥有自己的 Gateway / session / tools / 权限与本地日志。首阶段可使用官方本地 UI / CLI 作为交互入口，之后叠加 AnyLink 原生外壳、语音和形象。

不能只运行一个等待云端命令的节点，就宣称 Mac 已有完整 Agent。也不以自研固定文件动作循环替代成熟 harness。

## 配置隔离

使用 AnyLink 独立 profile、状态目录、工作区和回环端口，不覆盖用户已有 OpenClaw 配置。DeepSeek Key 不下发；本机只配置自有服务器模型地址与可撤销设备凭据。

模型 provider 指向自有服务器的 OpenAI-compatible 模型 API。memory 插件查询同一云端事实库，并在本地提示构建阶段注入当前 global / Mac 记忆。

## 本地职责

会话持久化、上下文预算、工具循环、任务恢复、取消、UI 状态、系统权限与主动联系。工具输出回到本地运行，必要的长期摘要才同步到记忆中心。

## 进程与权限

常驻生命周期由本机进程管理；睡眠、唤醒和权限撤销先更新本地状态。安装自启动前先明确二进制、配置与日志路径。更新不能清空 session 或未核验的工具结果。

本地 Gateway 只监听 loopback，浏览器 / 外壳使用本机凭据。文件、进程、桌面和麦克风按本机实际政策授权。

## 当前兼容项

已核对 npm `openclaw@2026.11.6` 的 engines 为 Node `>=24.16.0 <25 || >=26.1.0`。当前工程的 Node 22 开发环境不能直接作为该 Mac harness 的运行环境；需独立准备支持的运行时，不能只复制云端 Linux 镜像来冒充 Mac 原生执行。
