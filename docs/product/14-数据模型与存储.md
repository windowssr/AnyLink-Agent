# 数据模型与存储

## 云端权威

- `owners` / `device_bindings`：服务身份、安装绑定、公钥或凭据摘要、撤销与权限。
- `memories` / `memory_revisions`：global / device、来源、适用设备、当前版本、删除状态。
- `device_directory`：设备事实 ID / revision 的派生索引，可由当前事实重建。
- `model_requests`：设备、请求关联、模型、用量、时长与错误状态；默认不保存完整推理正文。
- `service_settings`：模型路由、配额和作为人格配置的版本化偏好。

这里没有运行中的云端 Agent、待执行的云端步骤队列或服务器任务调度租约。

## 本机权威

- harness 原生 session / transcript / run / tool call 存储。
- 本地 task 与 operation 的关联、权限快照、取消与对账状态。
- 已完成工具结果、后置条件和未同步结果摘要。
- 记忆缓存与已见 revision、UI 状态、语音 / 形象 generation。

优先复用 harness 支持的持久化，不跨进程改写其内部表。补充本地记录必须与原生 run ID 关联，不能产生第二套独立执行事实。

## 共享不等于复制权威

选择同步会话备份或任务摘要时，带 `origin_device_id`、原生 run / result 引用与 revision。云端副本不能被调度器重新解释为待执行指令。

## V0.1 数据迁移

保留记忆、修订、逻辑设备与现有审计。旧 `tasks` 只保留为历史待办，不自动导入本机可执行队列；旧云端对话只读导出，不能重放。旧 run 投影与云端 OpenClaw 状态作为历史数据保留至用户选择清理。
