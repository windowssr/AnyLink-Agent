# 用户体验与关键场景

## 入口

Mac 本地应用或本地 Gateway UI 是对话入口。输入、打断、工具进度、结果和权限提示都由 Mac Agent 处理。网页静态资源的托管位置不决定架构；对话必须提交到设备 Agent，而非云端 Agent API。

## 文件任务

用户在 Mac 说“读取这份笔记，整理后保存摘要”。Mac harness 读取当前目录与所需文件，经服务器模型代理取得工具决策，在本地执行并展示真实结果。服务器不生成另一套执行计划，不向 Mac 发出文件命令。

## 记忆

用户说“记住，我喜欢简短的中文回答”。本地 Agent 调用云端记忆工具，成功持久化后再确认。新会话先读取当前有效事实。用户在记忆页可更正和删除；这些是云端数据 API 的操作。

## 设备切换

另一设备启动自己的 Agent，取得同一 global 人格与长期事实，并读取适用该设备的事实。跨端继续同一会话需要显式会话迁移 / 同步，不把跨端记忆共享误报为逐字历史已同步。

## 后续跨设备任务

手机 Agent 把目标明确的请求交给 Mac Agent，由 Mac 自己校验授权、安排执行和返回证据。第一阶段不实现此链路。服务器若未来增加传输中继，也只能运送设备消息，不能据此取得规划和执行所有权。
