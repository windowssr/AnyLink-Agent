# AnyLink v0.10.0-preview.15 · 语音自动插话与整轮连续播报

本次相对 preview.12 修改 **Android App 和配套服务器语音网关**，电脑端、Web、SDK 和 MCP 没有修改。服务端包版本仍为 v0.9.2，协议仍为 v3.2；整轮连续播报需要更新配套服务器，不能只凭包版本号判断是否已升级。

## 通话中直接插话

- 本地识别模式中，用一个 `VOICE_COMMUNICATION` 录音会话持续监听，结合设备提供的回声消除、降噪、Silero 语音检测和本地转写结果确认插话。疑似插话降低播报音量，未确认时尽快恢复；确认后取消旧回复与播放，保留约 416ms 内存预录，减少丢首字。
- 在「保活 → 通话中语音自动打断」启用；首次另行下载约 629KB、固定 SHA-256 的语音检测模型。它与原来的约 199MiB 本地识别模型分别管理，权重不包含在 APK 或源码中。
- 静音和挂断停止通话录音；普通语音输入仍需主动点按开启。系统识别、缺少模型或初始化失败时保留轮流听说与点人物插话。
- 外放未启用设备 AEC 时保留点按打断。检测人声不能区分用户、电视或旁人的真实讲话；外放、耳机和复杂噪声环境仍需扩大验收，不保证所有设备都能可靠自动打断。

## 更连贯的 Momo 播报

- 模型文本边生成边追加到新的 HTTPS 连续合成接口，百炼 `server_commit` 自动处理连续输入，客户端不再每句手动提交合成。一轮回复共用一个音频流与一个 `AudioTrack`，减少句间合成及播放器重置。
- 默认仍为阿里云 `qwen3-tts-flash-realtime` 的 `Momo`，语速 1.12 倍。Key 仅由服务器读取，TTS 接口不上传本地识别录音。
- 服务端按每次重新鉴权的设备凭据隔离会话，限制会话数、输入文本、音频大小及总时长；输出受阻时暂停上游读取，取消会关闭整轮文本和音频流。
- 开口前无法使用连续流时，以收集到的同一轮文本回退原来的微软语音，再由 Android 系统 TTS 兜底；已发声的流中断时提示重试，不换声重播。Kokoro 不参与播报。
- 手机人设补充统一讲述者的规则，减少故事里的多角色配音式文本。同轮兜底固定、通话通知延后、文件预览、SVG 图标、悬浮透明度及人物显示修复继续保留。
- 口播文字在实际发声后显示，口型由真实 PCM 与播放头驱动。连续模式显示本轮口播字幕，服务没有提供逐字时间戳；模型本身仍可能因内容产生自然的语气变化。

## 升级与兼容

- 新版服务器通过 `/model/v1/audio/status` 的 `tts_continuous` 声明连续合成能力，新增 `POST /model/v1/speech/live` 与 `PATCH /model/v1/speech/live/:id`。原 `/model/v1/speech` 的 JSON/WAV/MP3 和逐句 PCM 接口继续保留，旧客户端兼容。
- 本次使用的服务器已部署连续合成网关；自建服务的配置见 [Android README](../../examples/android-native/README.md#云端-momo-配置仅服务器)。服务器不需要配置云端 ASR 才能使用手机本地转写。
- Android 12+，开发/debug 签名。升级安装保留已有模型及数据；新装仍需另行下载本地识别和自动打断模型。

## 验证与分发

- 93 项 Android 回归、37 项服务端单元测试（单元入口另跳过 5 项集成场景）、62 项数据库集成测试，以及 SDK、类型和协议检查通过。测试覆盖整轮单播放器、连续文本追加、鉴权隔离、取消、超时、背压和开口前兜底。
- 荣耀 BRP-AN80 / Android 15 私有版真机已启用 AEC 和降噪；用户确认无需点击即可插话，整轮连续播放后「明显连贯了，语速也合适」。一次 111 字符回复，识别结果到首声约 2.57 秒、首段排队到实际发声约 0.84 秒。数字为单次观测，不包含说话结束判定与转写，不是延迟保证。
- **Release 仅上传公开 APK、`release-manifest.json` 和 `SHA256SUMS`**。源码同步到 GitHub 与 Gitee，同名 tag 标识本次代码。公开 APK 使用原创 SVG 形象，不含私有 Live2D 模型、贴图、Cubism Core、ASR/VAD 权重或密钥。
- 私有 APK 仅保留本地，不作为发行资产。公开/私有开发包名与签名相同，覆盖安装会切换形象资源；自用 Live2D 设备继续使用本地 `-private.apk`。公开 APK 的素材隔离通过包检查，真机语音验收来自同源私有版。
