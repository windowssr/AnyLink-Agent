# AnyLink v0.10.0-preview.12 · Momo 流式播报与同步字幕

本次预览包含 **Android App 与配套服务器语音网关** 的修改，电脑端、SDK 和 MCP 没有修改。协议编号仍为 v3.2，服务端包版本号仍为 v0.9.2。发布内容累计包含 preview.8 之后的 Momo 接入、播报一致性修复和首声优化。

## 播报和字幕

- 接入阿里云百炼 `qwen3-tts-flash-realtime` 的茉兔 `Momo`，默认语速 1.12 倍。Key 仅由服务器读取，不写入手机或公开仓库。
- 新版 App 使用 `Accept: application/x-ndjson` 从既有 `/model/v1/speech` 接收 `start` / `audio` / `done` 事件，以 `AudioTrack` 播放 24kHz PCM16 单声道音频，收到首段即可起播，无需等待整句音频完成与文件解码。
- 普通聊天在模型生成短句时提前合成，直接使用原句，不再额外调用模型重写说话风格。陪伴视图按实际播放逐句展示；展开阅读随时可看完整文字。通话字幕只跟随当前播放句。
- 预取最多一句后续语音；嘴部使用 PCM 的 20ms RMS 与实际播放头，文件音频继续使用解码后的包络。取消或挂断会关闭请求、清空预取和播放缓冲。

## 播报一致性

- 保留原来的微软 `XiaoyiNeural`，再由 Android 系统 `TextToSpeech` 兜底；Kokoro 不参与播报。
- 同一轮回复一旦降级，不会在下一句跳回主音色，下一轮才重新尝试。已播放的音频流中断时明确提示重试，不换声音从头重播。
- 普通通知与跨设备回执在通话期间暂缓播报，挂断音效结束后继续；通知卡片仍按原流程显示。
- 修正任务回执“已计算是否改写，但入队时总是强制改写”的逻辑；长结果由服务器按共享人设精炼，保留原文称呼和语气，移除客户端另一套改写提示词。
- 「保活 → 大肥鱼的声音」提供试听、实际声音状态与「复制播报诊断」。记录最近 60 条来源、请求 ID、实际音色、阶段耗时及降级事件，不包含正文、录音、凭据或 API Key。

## 开口前等待

- 在连接与开始通话时预检身份及协议，同一连接实例缓存成功结果 60 秒；记忆、模型等服务器接口继续逐次鉴权。
- 聊天、控制与播报共享 HTTPS 连接池，各自保留独立的取消范围，停止播报不会取消聊天或控制请求。
- 设置 50ms 起播阈值目标，保留后续缓冲；设备状态查询不再阻塞监听启动，通话结束说话的判定等待由 1100ms 调整至 850ms。
- 诊断增加设备检查、记忆、模型首 token 与首句生成时间，便于区分网络、模型和合成等待。

## 升级与兼容

- **Momo 流式播报需要配套更新服务器并配置百炼 Key**，完整步骤见 [Android README](../../examples/android-native/README.md#云端-momo-配置仅服务器)。未配置 Key 时继续使用原微软主声音与系统兜底。
- 原请求 JSON 结构和默认 JSON/WAV/MP3 响应保留；未请求流式传输的旧客户端继续使用原格式。客户端根据响应的 `Content-Type` 处理首段前的微软兜底。
- 本地离线 ASR、系统识别、文件预览、SVG 图标、悬浮透明度与人物显示修复继续保留；这次改变的是播报链路，本地识别录音不会经 TTS 接口上传。
- Android 12+，开发/debug 签名。新装本地识别仍需另行下载约 199 MiB 模型，升级安装保留已有模型与数据。

## 验证与分发

- 87 项 Android Agent/Compose/phone 测试、13 项脚本测试、61 项数据库集成测试，以及 SDK、类型、协议检查通过；覆盖首段早于合成结束、播放时钟字幕、取消竞争、同轮降级、通知延后、预检缓存和连接复用隔离。
- HONOR BRP-AN80 / Android 15 私有版真机检查了可听见的 Momo 回复、字幕同步、句间接续和开口速度。一次观测首句生成到播放约 0.77 秒，识别结果交给 Agent 到开口约 2.5 秒；网络和模型响应会波动，数字不包含说话结束判定与转写时间，不是通用延迟承诺。字幕按短句同步；长时间后台通话、蓝牙/有线耳机、外放全双工及逐字对齐尚未完整验收。
- **Release 只上传公开 APK、`release-manifest.json` 和 `SHA256SUMS`**；源码由两个仓库和同名 tag 提供。公开 APK 使用原创 SVG 形象，不包含 Live2D 模型、贴图、Cubism Core、ASR 权重或个人密钥。私有 APK 仅保留本地。
- 公开版与私有版的开发包名和签名相同，覆盖安装会切换形象资源；自用 Live2D 设备继续安装本地 `-private.apk`。
