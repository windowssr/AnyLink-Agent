# Mac 客户端

> 历史方案：云端 Agent 架构，已于 2026-11-22 被边缘 Agent 架构替代。仅作历史参考，当前设计见 [产品文档](../../product/README.md)。
## 1. 默认技术方向

采用原生外壳、共享协议与 Web 形象渲染层。优先复用 OpenClaw macOS 节点和权限能力；产品聊天、记忆、任务和形象界面按统一交互改造。SwiftUI / WKWebView 是本方案的默认外壳选择，实际复用方式在客户端构建原型后固定。

V0 可以临时保留官方节点应用与开发界面两个入口；V1 必须提供一个用户可理解的安装、启动和设置体验，不能让用户管理多个含糊的后台助理。

## 2. 进程与模块

- 应用外壳：窗口、菜单栏、全局快捷键、设置和本地通知。
- 交互模块：聊天、任务、记忆、设备和形象视图。
- 媒体模块：麦克风、回声处理、声音焦点和播放器。
- 节点 / 执行模块：能力上报、原生 helper、资源锁和本地步骤日志。
- 同步模块：认证、API、事件游标、缓存和重连。

先做清晰模块边界，不强求全部拆独立进程。UI 与执行日志的生命周期必须分开；窗口关闭不删除已接受步骤。

## 3. 窗口体验

提供普通主窗口、可收起伴随窗口和菜单栏入口。伴随窗口可拖动、调整大小、关闭声音，不能遮挡系统关键操作。用户暂停形象时，任务仍可按授权执行。

默认只有用户显式开启才登录后启动。窗口可见、用户活跃和可以播报是不同状态；不要仅凭鼠标移动就自动抢走手机的语音焦点。

## 4. 本地权限与能力

麦克风、通知、屏幕录制、辅助功能和文件访问按能力分别管理。应用读取真实系统状态，失效后立即更新能力，而不是只保存一个“用户曾经同意”的布尔值。

桌面控制沿用所选 OpenClaw provider 的当前能力，不自动切换到另一种实现规避失败。原生 helper 不可用时拒绝相关步骤并给出可操作原因。

文件工具默认在用户配置的工作区内运行；路径通过本地规范化和边界检查。跨卷移动、同名覆盖、符号链接和权限变化要有明确处理规则。

## 5. 本地数据

系统安全存储保存设备凭据；本地数据库保存缓存、事件游标和执行回执。缓存带云端 revision，不能将本地旧事实覆盖服务器。

原始音频和截图默认短期或不落盘，任务证据按实际需要保存并上传。完整附件不进入普通日志。未同步回执在重启后优先恢复，不因清理聊天缓存而删除。

## 6. 休眠、断网与恢复

即将休眠或权限失效时，停止接受新交互步骤；能够安全结束的操作保存结果，其余记录待对账。唤醒后先恢复连接、绑定和未完成回执，再接受冲突任务。

服务器不可达时可查看缓存和编写草稿；默认不让客户端独立调用大模型或继续接受没有云端账本的新写任务。离线草稿重新发送时使用稳定请求 ID。

## 7. 更新与诊断

升级前停止新步骤认领，等待已接受操作到达安全点。数据库迁移必须保留回执。与服务器协议不兼容时保留只读和诊断入口，不继续派发未知格式操作。

诊断页展示连接、能力、协议版本、最近同步、待上传回执数量和错误编号。普通界面不展示内部密钥和完整模型请求。

## 8. 验收

冷启动、登录启动、窗口关闭、应用崩溃、helper 退出、权限撤销、休眠唤醒、网络切换、升级迁移和两台 Mac 同名场景都需验证。Mac UI 与节点执行的同一逻辑设备映射必须一致。
