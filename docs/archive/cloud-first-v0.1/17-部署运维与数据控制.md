# 部署运维与数据控制

> 历史方案：云端 Agent 架构，已于 2026-11-22 被边缘 Agent 架构替代。仅作历史参考，当前设计见 [产品文档](../../product/README.md)。
## 1. 最小部署

V0 使用一台自管主机：反向代理、产品 API、worker、OpenClaw Gateway、PostgreSQL 和附件存储适配。模型与语音推理默认调用外部 API，不把本地大模型 GPU 部署作为第一版前提。

模块可以先打包为少量容器或服务，分别限制资源和健康检查。硬件大小由原型的常驻内存、并发媒体和附件负载测定，不在无测量时填“最低配置”。

## 2. 网络入口

公开产品 API / WebSocket 使用一个受认证的 TLS 入口。Gateway 管理入口只对受信管理网络开放。节点连接通过专用受限入口或私网连接 Gateway，不能向普通客户端分发管理员凭据。

音频流、事件流和附件传输分别设连接 / 体积 / 超时限制，避免一个大上传阻塞所有聊天。服务器到 provider 的出站凭据不进入客户端日志和配置包。

## 3. 配置与密钥

配置区分公开产品设置、内部运行参数和秘密。DeepSeek / 语音 provider Key 放服务器的受控秘密存储；设备密钥保留本机安全存储；数据库凭据按服务角色发放。

密钥轮换不修改用户记忆。配置变更版本化，新运行捕获新配置，旧运行按允许策略结束。检测 provider 配置可用时只做显式的最小验证，不在服务启动时无限调用付费接口。

## 4. 持久 worker

worker 使用数据库认领、租约和 outbox。进程内定时器只负责唤醒扫描，不承担持久状态。宕机重启后扫描过期认领、待投递事件、未对账步骤和脏索引。

停止服务时先撤销新认领，尽可能等待安全点，再退出。未收尾动作标记待对账；不能在 shutdown hook 里把所有 running 都改成失败。

## 5. 监控

| 模块 | 指标 |
| --- | --- |
| 接入与会话 | 请求接受率、提交未知数、运行失败率、重连与补读时长 |
| 记忆 | 查询时长、scope 错误、索引滞后、冲突率、删除清理积压 |
| 任务 | 等设备时长、认领延迟、未知结果数、回执积压、重复派发拒绝 |
| 模型 | 提供商错误、超时、token 用量与预算消耗 |
| 语音 | 端点到首声 P50/P95、打断时延、ASR/TTS 错误、播放焦点冲突 |
| 通知 | 触发 / 延后 / 跳过、provider 接受、设备接收、重复展示 |
| 客户端 | 崩溃、能力失效、渲染帧率、媒体资源与耗电 |

日志默认记录请求 / run / task / step 关联 ID、状态和时长，不默认记录完整聊天、记忆正文、屏幕和音频。需要详细诊断时使用限时开关与可见范围。

## 6. 费用与资源控制

主人可以设置模型月度预算、单任务 token / 工具步数、语音时长和附件容量。长循环达到预算时暂停并保存进度，不无声改用别的付费 provider。

记忆抽取、摘要和嵌入批量合并，避免每条消息触发多次重复模型调用。重试继承同一请求 / 任务身份，同时受最大次数与总期限限制。

## 7. 备份和恢复

产品数据库、Gateway 状态与附件分别备份，并记录共同恢复点 / 水位。删除墓碑和关键撤销记录保留到独立的恢复控制记录中，以减少恢复旧快照后重新暴露已删除数据或旧授权的风险。

初始运营目标建议为 RPO 不超过 24 小时、RTO 不超过 4 小时，属于需要实际恢复演练验证的目标。若更短数据损失窗口重要，增加连续日志归档后重新验收。

恢复流程：进入只读恢复模式 → 恢复数据 → 应用最新可得删除 / 撤销记录 → 禁止自动派发旧任务 → 核对设备回执与绑定 → 重建派生索引 → 验证后开放写入。

如果无法获得足够新的删除 / 撤销记录，不自动恢复普通查询与执行；向主人说明恢复点限制。不能仅凭数据库启动成功宣称恢复完整。

## 8. 升级和回退

升级前冻结新派发、备份、运行迁移和兼容测试。先验证测试设备，再更新真实设备。数据库采用可回退的分阶段迁移；不能只回退二进制却保留不兼容 schema。

回退后仍需要对账升级期间接受的步骤。任一不兼容客户端只保留能证明安全的只读入口，不派发未知命令。

## 9. 删除与导出

主人可以导出结构化记忆、设备目录、任务结果和必要附件。会话导出通过 Gateway 支持的路径取得，保留来源标记。

删除操作明确区分事实、聊天、附件和整个设备。数据导出 / 删除完成状态由后台实际处理进度决定，不在前台点按钮后立即声称所有备份都已清理。

## 10. 运维验收

至少做一次从备份启动的完整恢复，验证记忆不复活、未知动作不重放、设备重新验证、附件引用有效和版本匹配。告警优先关注未知副作用和持续失败，不为每次短暂断网制造噪声。
