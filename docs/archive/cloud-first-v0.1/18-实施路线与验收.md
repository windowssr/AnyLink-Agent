# 实施路线与验收

> 历史方案：云端 Agent 架构，已于 2026-11-22 被边缘 Agent 架构替代。仅作历史参考，当前设计见 [产品文档](../../product/README.md)。
## 1. 实施方式

按可验证的纵向闭环交付，不先铺完整 UI 再发现运行时不适配。每阶段有明确产物、演示和退出条件，不在缺少部署条件时估算精确工期。

## 2. 阶段计划

| 阶段 | 交付物 | 完成条件 |
| --- | --- | --- |
| P0：接缝验证 | 固定版本、请求关联、可信身份、Mac 回执原型 | S01/S02/S03 通过；成本过大时调整底座 |
| P1：云端文字闭环 | 单主人、Mac/Android、同人格、DeepSeek、会话映射 | 两端可以交流、切换会话、断线重连而不重复提交 |
| P2：层级记忆 | 事实修订、设备 scope、目录、管理 UI | 跨设备召回、更正、删除和索引滞后测试通过 |
| P3：可靠设备任务 | 文件整理垂直场景、账本、回执、Workboard 投影 | 离线、重启、回执丢失、取消与撤销通过 |
| P4：统一客户端 | 原生外壳、任务 / 记忆 / 设备页、基本形象 | 一套清晰入口；形象失败不影响核心使用 |
| P5：语音与主动联系 | 流式 ASR/TTS、声音焦点、提醒与通知 | 可打断、多端去重、延迟报告和后台边界明确 |
| P6：扩展能力 | 实时语音模型、更多 GUI / 手机任务 | 每类能力独立验收，不能默认继承可靠性 |

## 3. 功能验收场景

| 编号 | 场景 | 预期 |
| --- | --- | --- |
| A01 | Android 明确保存偏好，Mac 新开会话查询 | 召回当前全局事实并有来源 |
| A02 | Android 告知 Mac 路径 | 来源记 Android，适用范围是 Mac |
| A03 | 两端同时更正同一事实 | 冲突显式处理，不静默覆盖 |
| A04 | 删除后向量索引暂未刷新 | 查询仍不能返回已删除事实 |
| A05 | 手机发起任务，Mac 离线 | 持久等待，不改到服务器执行 |
| A06 | 等待期间服务器重启 | 任务仍存在，当前授权重新检查 |
| A07 | Mac 已执行，回执上传失败 | 重传回执或对账，不重复副作用 |
| A08 | 动作后本地进程崩溃 | 进入不确定结果处理，核对后置条件 |
| A09 | 取消和完成同时发生 | 真实已完成部分保留，任务终态一致 |
| A10 | 租约过期，旧 worker 恢复 | 旧派发被拒，未知旧动作先对账 |
| A11 | 撤销配对后迟到命令 | 不继续产生新动作 |
| A12 | 两设备同时进入语音 | 只有合法焦点设备播放与采集 |
| A13 | 用户插话 | 旧 generation 音频和口型停止 |
| A14 | 语音关闭但后台任务已接受 | 任务不因媒体关闭而丢失 |
| A15 | 同一任务完成事件重复投递 | 一个 interaction，多端状态一致 |
| A16 | 恢复旧备份 | 删除墓碑生效，旧任务不自动重放 |
| A17 | 客户端事件游标过期 | 重新拉快照，不漏掉关键状态 |
| A18 | 原生权限失效 | 在线但未就绪，任务等待明确原因 |
| A19 | 模型绕过任务写工具 | 被策略阻止，不产生账本外副作用 |
| A20 | 形象渲染器崩溃 | 文字、任务和已授权执行仍可用 |

## 4. 评测数据

记忆评测至少建立 100 条人工可核对用例，覆盖全局事实、设备事实、同名设备、更正、时间、冲突、删除和错误范围。报告召回是否正确、引用是否有效、是否串域；串 owner 或已删除事实暴露属于阻断问题。

任务测试先在临时目录与可控应用中进行，建立确定性文件输入和后置条件。故障注入覆盖接受前、接受后、动作后、回执写入后、上传后和服务端提交前，不只测正常成功路径。

语音每种主要设备 / 网络组合建议至少 100 轮，记录中文短句、长句、噪声和打断。不能只挑最好的几次演示作为延迟报告。

## 5. 非功能目标

| 指标 | 初始目标 / 约束 |
| --- | --- |
| 语音首声 | 固定测试条件下 P50 ≤ 1.5 秒、P95 ≤ 3 秒；待原型校准 |
| 本地停止旧播放 | 目标 ≤ 150 毫秒，统计到真正停止可听音频 |
| 形象 | 活跃目标 30 FPS，低性能档可 15 FPS，后台停止渲染 |
| 记忆一致性 | 修订提交后，直接读取返回新版；索引滞后不得暴露删除项 |
| 任务可靠性 | 已持久接受的任务不因普通进程重启丢失；未知副作用不盲重试 |
| 通知 | 重复事件不创建重复 interaction；provider ACK 不当用户已读 |
| 恢复 | 初始 RPO ≤ 24 小时、RTO ≤ 4 小时；需演练验证 |

这些数字不是当前测试结果。若原型不满足，修改设计或明确缩小发布范围，并更新决策记录；不能在文档中把目标改写成已实现能力。

## 6. 发布门槛

每次发布记录版本、兼容矩阵、已支持能力、未通过项和回退方式。记忆串域、任务重复副作用、旧绑定仍可执行、不可解释的未知状态丢失均阻断相关功能发布。

手机任意 App GUI、后台语音、形象悬浮窗等可以作为关闭的实验功能存在；只有通过实机验收的能力才能默认开启。

## 7. 设计交接清单

实施者应先完成 [待验证项](19-架构决策与待验证项.md) 的阻断原型，再把 [接口协议](15-接口与事件协议.md) 转为 schema 与契约测试，把 [数据模型](14-数据模型与存储.md) 转为迁移，把本文件场景转为自动化 / 真机验收记录。

本轮交付为设计基线，不包含这些实现、测试通过记录或部署结果。
