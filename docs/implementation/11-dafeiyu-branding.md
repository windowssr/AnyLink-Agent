# 大肥鱼界面标识

本机固定 OpenClaw 2026.11.6 的 Control UI 使用大肥鱼头像作为侧栏品牌、助手面孔、欢迎页形象和页签图标。主助手及陪伴助手通过官方 `agents.entries.<id>.identity.avatar` 配置本地头像，图片位于各自工作区的 `avatars/dafeiyu.png`。用户账户照片、普通工具图标和其他服务商标不替换。

头像直接由已经安装的本机 Live2D 模型渲染，保持原人物比例；不读取桌面、聊天、麦克风或摄像头，不调用图像模型或重新下载完整人物。输出为 512 px 头像、32 px 页签图标和 180 px 触摸图标。保留既有作者来源与模型许可说明；生成图片保存在忽略的 `data/mac/branding`、本机工作区及独立 runtime 中，不随 Git 发布。

## 安装与生效

```bash
npm run desktop:branding
node mac/cli.mjs config validate
```

首次会编译一个临时 WebKit 离屏渲染工具，后续使用已有头像。人物换了，可运行 `npm run desktop:branding -- --regenerate`。编译器模块缓存、临时静态资源和可执行程序在结束或失败后立即删除，不创建新的 `.app` 安装包或大体积备份。

`apply.mjs` 只在本项目的回环 Gateway 和固定版本上工作，安装受限的 CSS／JS 外观适配、更新 favicon 与 Web App manifest，并设置两位本机助手的头像。侧栏和品牌组件采用样式覆盖，不往响应式组件中插入子节点。适配脚本只检查已知品牌容器及页面标题，不读取输入框、消息正文、令牌、响应数据或本地存储；页标题仅替换品牌后缀，保留用户自己的会话标题。

原生 `.app` 无需重建。Control UI 会缓存入口 HTML 及静态资源，因此首次应用或更新适配后需在本机任务空闲时平滑重载 Gateway，再重新加载聊天页；头像配置采用 Gateway 的正常配置更新机制，不更改模型、工具权限或记忆数据。

`mac/start.mjs` 在以后启动时重新应用已生成的皮肤，避免重新安装相同 runtime 后图标丢失。不兼容的 runtime 不应用适配，也不阻止 Agent 启动。升级 OpenClaw 版本时必须重新核对入口与品牌容器，不自动跟随新版本。

## 还原

```bash
node mac/branding/restore.mjs
```

此命令恢复一次性保存的原始 UI 文件和先前的头像字段，不恢复整份旧配置，不覆盖后续模型、权限和设备设置。随后在 Gateway 空闲时重启服务并重新加载页面。`disabled` 标记停止启动时自动重套皮肤；再次运行 `desktop:branding` 会重新启用。

只保存一组原始入口、图标和受保护配置，目录为 `data/mac/branding/original-control-ui` 与 `openclaw.before-branding.json`，配置权限 0600，目录 0700。技术名称、协议、命令路径及原有上游版权说明保留。

- 重复应用只保留一组适配入口；配置校验通过，模型、工具、插件、Gateway 和定时任务配置与应用前一致。
- Gateway 就绪，图标、manifest 和适配资源返回 HTTP 200；重载后提供最新适配内容。

- 源码凭据扫描通过；图片、受保护配置和本机运行数据排除在 Git 外。离屏渲染的临时目录与编译缓存已清除，本次没有创建新的 `.app` 备份。

这是界面换标验证，没有再次发起模型请求或重跑电脑操作任务。
