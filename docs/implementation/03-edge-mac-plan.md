# Mac 边缘 Agent：修正后的施工基线

日期：2026-11-22。状态：目标与施工顺序已校正，**尚未安装本机 harness、上线模型代理或完成新架构验收**。

## 需求与旧实现的差异

用户要求与边缘设备交互，设备运行成熟 Agent，服务器只是长期记忆中心与模型调用处。旧 V0.1 把聊天 API、上下文、工具循环和任务意图放在云端，实际是“云端 Agent＋终端界面”，不符合此边界。

“Mac 收到服务器指令后执行固定动作”的执行器也不能解决这个差异。它仍把控制权留在云端，且重复建设成熟 harness 已有的本机工具循环。因此该未提交实现已撤回，仅在被忽略的本地 artifacts 留档，未推送、未部署。

## 目标

```text
你 ⇄ Mac 本地 UI ⇄ Mac 上的成熟 OpenClaw harness ⇄ 本机工具
                         ├⇄ ywc 记忆 API ⇄ PostgreSQL
                         └⇄ ywc 模型代理 ⇄ DeepSeek API
```

Mac 持有 session、context、run、tool loop、任务结果与系统权限。服务器只处理推理请求和记忆数据，不拥有交互 Agent，也不领取和派发本机步骤。

## 可复用部分

- PostgreSQL 的 global / device 记忆、revision、来源与软删除。
- 当前事实生成的设备目录、文本检索和条件更新。
- 服务鉴权与 SSH 隧道的基础设施，可进一步补设备凭据。
- 项目级部署、备份和回退机制，以及 Gitee 发布记录。

## 要替换或退役的部分

- 云端聊天提交与 SSE 不再是新用户对话入口。
- 云端 `ChatService` 的上下文组装与工具循环改由本机 harness 承担。
- 云端 OpenClaw 不继续担当设备对话的大脑；Mac 验收后停用，保留旧状态供只读导出。
- 云端任务表只保留历史待办，不自动变成本机可执行队列。
- 不开发云端 claim / lease → 固定文件动作执行器作为主方案。

## A. 标准模型代理

在产品服务添加设备认证的 `/model/v1/models` 与 `/model/v1/chat/completions`（拟议路径）。服务器使用已有 DeepSeek Key 直连提供商，固定允许模型、超时、请求大小与单设备预算。

保留模型消息、工具 schema、工具调用、工具结果、SSE 和用量。代理不执行工具，不启动 session 或 Agent，不保存一份可运行的用户任务。不把旧云端 OpenClaw Agent endpoint 包在代理后面。

默认日志只记录关联 ID、设备、用量、时长和错误。转发必然携带推理上下文，不能宣称服务器完全看不到内容；也不能因此默认长期落盘全部对话。

## B. 本机成熟 harness

隔离安装正式 OpenClaw 与兼容 Node；使用独立 profile、状态目录、工具工作区和 loopback 端口。npm 已核查 `2026.11.6` 需要 Node `>=24.16.0 <25 || >=26.1.0`，本机现有 Node 22 不足。

优先使用官方本地 Gateway UI / CLI。自定义 provider 连接上述模型代理；本机只持设备服务凭据，不持 DeepSeek Key。多轮工具与执行由 OpenClaw 原生能力处理。

## C. 云端记忆接缝

本地插件在正式扩展点查询 global 与当前设备事实，注入本地上下文。记忆工具调用现有服务器数据 API；来源由认证绑定，适用设备仍显式校验。

明确记住才保存；更正走 revision，删除即时失效。本地 session / 临时操作日志不等于第二套长期事实，但不得让原生自动 memory 与云端事实形成互相冲突的写入权威。

## D. 验收顺序

1. 模型代理独立通过流式、tool_calls、工具结果与取消 / 错误测试。
2. Mac 本地 UI 发起对话，通过代理获得真实 Flash 响应。
3. Mac harness 真实完成一个文件任务，确认本机工具结果与后置条件；服务器没有工具执行循环。
4. 本地 Agent 保存 global / Mac 事实，新会话召回，更正与删除使用当前版本。
5. 进程 / 网络中断后查原运行与工具证据，不重复执行未知写操作。
6. 停止旧云端 OpenClaw，再次验证 Mac 闭环成立。

完成这组验收后才发布边缘接入版本。旧 V0.1 的 14 项自动检查和 9 项模型检查继续作为历史原型证据，不能改名冒充新架构已实现。

Android、设备间任务协作、语音和形象后续接入。若未来需要中继，仅属于通信设施，不能静默恢复云端 Agent 调度。
