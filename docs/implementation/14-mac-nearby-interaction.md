# V0.7：Mac 人物身边的交互与执行闭环

本轮把 Mac 人物点击和 Dock 再次唤起改为就近交互。保留现有正常比例 Live2D 人物、云端模型代理、统一记忆、本机 main Agent 与工具权限。Android 和自动学习本轮不变。

## 使用流程

1. 单击人物或使用应用菜单“叫大肥鱼”：停止旧播报和漫游，人物转向用户，身边出现可输入的一小块面板。不会自动打开完整聊天。
2. 输入后按回车或“交给我”：在稳定的本机 main 会话中提交一次。人物进入思考，工具开始后进入执行状态；此时暂停漫游和主动招呼。
3. 搜索文件时使用已有 `anylink_mac_search_files`。卡片显示工具回执中的文件名、路径、搜索不完整标记，支持在访达定位和复制路径。不从模型回答里猜文件路径。
4. 最终回答沿用已同意的甜妹声音，并保留本轮结果以便查看。“完整记录”是用户主动选择的辅助入口，审批或故障也可从此处理。
5. 收起面板后，视线、姿态渐渐回到待机，稍后恢复原有陪伴和漫游。执行期间收起仅隐藏面板，不等于取消任务；重新点击仍是同一件事。

本轮“叫她”指点击、Dock 或应用菜单；没有新增后台唤醒词和录音。原先的日常对话气泡与右键设置菜单仍关闭；新增面板用于输入和真实任务结果。

## 实现边界

`CompanionInteraction` 管理稳定 session、单次提交、run 绑定、接收早于提交确认的事件、取消、最终回复和未知结果。复用已有签名 `VoiceGateway` 的聊天读写连接；不会把设备控制迁回服务器，也不创建另一个负责执行的陪伴 Agent。

`CompanionSurface` 是独立原生面板，跟随人物位置并避开屏幕边界，支持负坐标显示器。动画渲染器继续只接收数值状态，不接收输入文本、结果正文、令牌或文件路径。新窗口不增加网络监听。

插件通过官方 `before_tool_call` / `after_tool_call` 钩子投影工具状态，复用现有短期私有事件目录和租约。仅文件搜索工具的结构化 `details` 可以产生文件卡片；其他工具只投影名称与失败标记。文件内容、命令输出、完整参数不会进入形象事件。

人物表现新增接待、思考、执行、展示及恢复状态。视线、倾斜、俯仰和身体重心按时间渐变；指向、抬手和返回动作受同一中断序列控制。结果出现后看向面板；减少动态效果仍生效。本轮没有补新的步态或坐姿资产，不把平移称为完整行走动画。

## 中断、恢复与结果真实性

- 同时只接受一条本地提交。每条消息有独立幂等键，订阅绑定稳定会话，回复绑定实际 run。
- 取消先停止本地声音，再取消指定 run。提交确认尚在途中时，等待实际 run 后取消；取消失败或未确认显示未知，不宣称已停止远端执行。
- 取消后迟到的回复和工具结果不会重新播报或恢复旧结果卡片。
- 断线、超时、睡眠和程序退出不会自动重发已提交消息；重启保留未知状态。模型未收到的连接失败可明确区分。
- 工具失败与本轮结束分别呈现。找到部分文件不代表已经搜遍电脑；点击定位时再次检查文件是否存在。
- 本轮结果没有新增长期聊天缓存；原有 OpenClaw 会话记录、云端记忆和权限继续沿用。

## 验证与发布

验证包含 Swift 状态机（确认前事件、跨 run 隔离、取消竞态、未知状态恢复、工具失败）、多屏定位、Node 投影边界、渲染姿态过渡，以及真实模型和原生界面验收。实际结果另记录在文末。

构建使用 `node mac/build-app.mjs`，安装使用 `node mac/install-app.mjs`。正常退出旧窗口程序后替换应用；插件更新在本机 Gateway 无任务时正常重启载入。安装器保留上一版应用，回退时同时恢复本轮修改的本机插件代码。无需服务器发布、数据库迁移或新的系统授权。
