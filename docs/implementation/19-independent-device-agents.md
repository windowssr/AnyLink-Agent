# 独立设备 Agent 与统一云端连接

修订：2026-11-22。此文取代 Android 原生 0.2.x 的 Gateway companion 接入方案。历史 tag、报告和旧手机／电脑原型保留，不能作为当前架构验收证据。

## 产品不变量

用户与当前设备的 Agent 交互；每台设备只需连接 AnyLink 服务器。会话、工具选择／执行、界面、权限、取消和结果展示归设备。服务器拥有全局／设备记忆、可选模型调用代理和授权的跨设备任务中继，不运行 Agent 循环，也不远程替手机思考或执行。

Mac 可继续使用 OpenClaw harness，手机本地使用原生 `DeviceAgent`。第三方项目可使用 JS／TS SDK 或 HTTP 协议适配自己的 harness；不必安装 OpenClaw，不必采用 AnyLink 的形象或模型代理。协议发现版本仍为 1.0，新增 `GET /edge/v1/link/peers` 是向后兼容的授权目标发现接口。

## Android 修正

- 独立 `AnyLinkActivity` 取代旧 companion launcher。产品 Manifest 不注册旧 MainActivity、节点服务、通知／分享／Wear 接入，启动不会构造 NodeRuntime。保留上游构建源码用于可重复生成，不将旧能力冒充新产品能力。
- App 验证 HTTPS URL、协议名和云端设备 ID。Token 不跟随重定向；客户端关闭网络失败自动重试。远程禁止明文 HTTP，回环开发隧道除外。
- Android Keystore 加密凭据到私有 SQLite；会话／工具操作／便笺按服务器＋设备身份分库。重启把未结束运行标为 unknown，不自动执行。
- 每轮读取当前云端记忆，原生处理 SSE，完整终止后才执行工具，最多六次模型调用，顺序执行工具。云端接收的工具是模型上下文定义，实际调用仍由手机执行。
- 手机工具：基础状态、私有便笺、统一记忆、表情、通用跨设备任务。其他手机 App 控制需要后续原生能力和系统权限；本次没有继承官方 Gateway 的全部手机能力。
- 语音由系统识别和 TTS 提供；可显式打断当前播报和模型任务。未承诺自动开口打断或固定声音。原来的微软 Gateway 语音验收属于旧链路，不能用于本次手机语音结论。

## 跨设备工作

1. Mac 本地配置搜索根目录，启动独立 SDK Worker，注册 `files.search`。无本机策略则不开任何目录。
2. 主人授权手机设备 → Mac 设备 → 该能力。云端 `peers` 只返回该来源获准的目标能力，不展示其他来源的授权。
3. 手机 Agent 下发意图，云端绑定认证来源和凭据身份，持久排队。
4. Mac 原子领取、检查实际任务状态，将 started 写本地 SQLite 后，按既有只读策略搜索。不读取内容、不使用 shell、不跟随软链接。
5. Mac 持久 finished 结果，再上传回执；丢失上传确认只恢复结果，不重复搜索。手机面板定期读取真实任务状态，模型也可查询。
6. Mac 离线时 queued，任务到期后 expired。手机自己聊天和工具不等待 Mac；last_seen_at 只是凭据活动时间，不代表 Worker 在线。

原有专用 Mac peer HTTP 入口为旧客户端保留，不是 Android 0.3 主线。旧配置不自动删除，避免破坏用户已有会话或独立原型。`mac/start.mjs` 新增通用 Worker，仍将 OpenClaw Gateway 限定在本机。

## 部署与验收边界

ywc 的 Compose 仍只绑定回环，不在本次替换既有 Nginx 或自行编造域名、证书。USB／SSH 转发用于开发；独立远程手机使用需要部署者提供 HTTPS 入口。手机连服务器与服务器公网可达是两件独立的部署条件。

自动测试分别覆盖：原生真实 HTTP 工具循环与断流、界面入口、SQLite 重启；SDK／服务器真实 HTTP＋PostgreSQL 授权和任务生命周期；Mac 文件名只读策略。额外真实云端验收只使用已授权开发预览身份、唯一测试标记并清理自己的事实。真机 GPU、麦克风、系统 TTS 和后台生命周期不由这些测试代替。
