The model is downloaded separately after the user selects download. Model files
are verified against pinned SHA-256 digests before use and stored in the app's
private files directory. Speech recognition runs locally and does not upload
recordings. Sending the resulting text in chat follows the existing chat flow.
Contextual biasing includes the application character name 大肥鱼. It does not
replace arbitrary recognition results or add test phrases to the language model.
